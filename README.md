# 바다가소 배포 파일

[바다가소 스토어](https://badagaso.pages.dev)에서 받는 윈도우 프로그램 설치 파일을 모아 두는 곳입니다.
소스 코드는 여기에 없습니다.

| 앱 | 하는 일 | 받기 |
|---|---|---|
| AgentGo | Claude Code 를 폴더별로 골라 Windows Terminal 탭으로 띄우는 런처 | [Releases](https://github.com/Badagaso/releases/releases?q=agentgo) |
| AgentSweep | 근거를 붙여 보여 주고, 승인한 것만 지우는 PC 정리 도구 | [Releases](https://github.com/Badagaso/releases/releases?q=agentsweep) |

- 코드 서명이 없어 처음 실행할 때 'Windows의 PC 보호' 창이 뜹니다. **추가 정보 → 실행**을 누르세요.
- 각 릴리스에 SHA-256 해시를 적어 둡니다. 받은 파일은 PowerShell 에서 `Get-FileHash 파일이름` 으로 확인할 수 있습니다.
- 의견·리뷰: https://badagaso.pages.dev 의 앱 카드에서 남겨 주세요.
